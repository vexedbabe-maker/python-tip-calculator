# Python Tip Calculator

A beginner-friendly Python program that calculates tips, total bills, and how much each person owes when splitting a bill.

## Features

- Calculates the tip based on a percentage.
- Calculates the total bill, including the tip.
- Splits the total bill between multiple people.
- Checks that the number of people is greater than zero to prevent division-by-zero errors.

## Technologies Used

- Python 3
- Python f-strings
- User input and type conversion
- Arithmetic operations
- `if/else` conditional statements

## How to Run

1. Make sure Python 3 is installed.
2. Download `tip_calculator.py` from this repository.
3. Open a terminal in the folder containing the file.
4. Run:

   ```bash
   python3 tip_calculator.py
   ```
